# Campus OS - Academic & University Semester Manager for Obsidian

[![Obsidian Plugin](https://img.shields.io/badge/Obsidian-Plugin-7C3AED?logo=obsidian&logoColor=white)](https://obsidian.md)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/version-1.0.0-10B981.svg)](https://github.com/Nelxson2099/obsidian-campus-os/releases)

**Campus OS** is a luxury, cyber-aesthetic academic operating system built natively for Obsidian. Manage your university, degree, semesters, subjects, strike-through task checklists, and export complete semester reports to clean Markdown.

---

## ✨ Features

- 🏛️ **Fully Customizable University & Degree**: Configure your institution, degree program, current semester, and academic year.
- 🎨 **Luxury Cyber UI**: Translucent glass cards with color-coded subjects, neon glows, and smooth micro-interactions.
- 📊 **Semester Progress Bar**: Real-time progress bar tracking completed vs pending tasks across all enrolled subjects.
- ✅ **Interactive Checklist**: Strike-through task management with due dates, grades, and weight percentages.
- 📄 **One-Click Semester Export**: Export your entire semester curriculum, notes, and task progress into a beautifully structured Markdown note in your vault.
- 🔄 **Safe Semester Reset**: Archive completed semesters safely into an archive folder and start fresh for the next academic cycle.
- 🌐 **Automatic Bilingual i18n**: Adapts instantly to your Obsidian language (English / Español).

---

## 🚀 Installation

### Option 1: Community Plugins (Recommended)
1. In Obsidian, open **Settings** → **Community Plugins**.
2. Search for **Campus OS**.
3. Click **Install**, then **Enable**.

### Option 2: Manual Installation
1. Download `main.js`, `manifest.json`, and `styles.css` from the [Latest Release](https://github.com/Nelxson2099/obsidian-campus-os/releases).
2. Create a folder named `obsidian-university` inside your vault's `.obsidian/plugins/` directory.
3. Place the downloaded files into that folder and reload Obsidian.
